# MiggyCodingg.github.io
EE021 Midterm Project: Microcontroller digital synthesizer. Made using breadboard, wires, Pico microcontroller, potentiometer, piezo speaker, OLED screen to change, play and display waves. Uses MicroPython to make, change, display and record frequencies. Also uses Python to analyze and store frequencies in files, as well as graphing the waves.
